## Checked and found sound

- Verdict mapping (§3.3, §4): every (holds, fails, undefined) pattern maps to exactly one verdict (`aggregate.py:159-169`). A deterministic FAILS needs no minimum count. The quantitative tests need ≥ 16 defined worlds and a Wilson bound ≥ 0.80.
- Wilson rule: the minimum HOLDS counts for n = 16–30 were recomputed. With 30 defined worlds the rule is exactly 28/30. Every entry of the §7 power table matches, and so does "0.003 at 0.71". No (n ≤ 30, s) gives a bound within 0.0006 of 0.80, so the float comparison and the three-decimal print cannot contradict each other.
- Fixed wording (§4) in `aggregate.py`: deterministic and quantitative HOLDS/FAILS, the G1 failed parts, the G8 FAILS and hypothesis sentences, the T-1 sentences in §4 order (also with "insufficient worlds"), the HOLDS-only T-1 caveat, the insufficient-worlds sentence, the limitation sentence and the expected-verdict paragraph. All match the pre-registration apart from dropped section tags.
- First failing world: records are generated and kept in draw order, so the first FAILS is the smallest draw index.
- UNDEFINED: the conditions of G6, G7a, G8 and T-1 match §3.2. G1–G5 never return UNDEFINED. The sentinel flag cannot be reached by data.
- T-1 judge and structure arms match §3.2 and the F3 text. Interface facts and Datalog are monotone, so uncertainty does not increase as α falls, and uncertainty order equals α order.
- k-invariance (R1-5): pass-1 facts keep their status in pass 2, so the verdict view, uncertainty, new_true and new_false depend on α only.
- G7a: echo, all_unknown and all_both have new_true = 0 by definition. all_true and all_false fail fidelity and deviation by wide margins. The oracle has new_true = 1, new_false = 0, deviation 0 and uncertainty 0, so the anchor holds whenever the oracle is feasible.
- G1 anchor (iii): the median own-class typicality of the normal entities was 0.72–0.89 on 40 development worlds, so (iii) is not a likely spurious FAILS.
- Twins: each can make its test fail. N1a breaks (i), N1b breaks (ii), N2 gives h1 ≠ h2, N3's default units stay decided after ablation, N5's centers move with D_validate, N6's OBSERVED hypotheses lie outside F1, N7 scores all_true, N8 raises deviation by ≥ min(k, n)/n_decided, and NT adds +1/5 at the lowest uncertainty. N4 separates robustly in practice (A11). No twin can pass through UNDEFINED unless the fixed system is also UNDEFINED.
- F1, F2 and F4 cover the decoder (pass 1, the ranked candidates with scores, the kept top-k, pass 2 from the independent hypotheses, statuses), H, PCM (centers, flags, iterations), class and relation units and interface facts. `audit/indep` imports only itertools and math.
- F3 instructions vs code: the metric definitions, feasibility, front order, hypervolume, G7a (oracle and baselines), G8 (the hypothesis-existence test is equivalent to "kept candidates > 0"), T-1, the structure fields, the Wilson recipe and the first failing world all agree with the run's code.
- Exact arithmetic: every comparison with τ, ε_f, ε_d and δ is on Fractions. The (p, q) array encoding is exact. The I-6 arm uses raw denominators.
- Runner (real mode) implements §8 steps 9–10: versions, manifest verification, unique commits with `--full-history`, ancestry on `origin/main`, manifest coverage, a clean frozen tree, SALT naming the freeze commit and core hash, the τ recheck, CAL_WORLDS equality, F1/F2/F4 before any check, no output before the table, and no overwrite.
- Seeds: the formula and roles match §7. The real range 1 000 000 … 1 000 999 999 is disjoint from the development range. Everything after the salt is deterministic, so nothing can be fished by rerunning.
- World validity matches D5 (PCM usable, \|H\| ≥ 10, defined τ metrics for calibration worlds, generator failure, at most 200 draws).
- G8 definedness depends on (α₀, k = 10) only, while violations at any α count. This is as pre-registered (noted, not a defect).
