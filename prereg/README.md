# prereg

The pre-registration of Tesaron v0.2 and its records.

- `PREREG_v0.2.md`: the pre-registration (questions, criteria, controls, grid, run plan, freeze).
- `F4_PREFREEZE.json`: the fidelity controls F4 and F1 on 20 development worlds, run before the freeze.
- `DRAW_STUDY.json`: the calibration-draw study on development worlds (design quantities, PREREG §7).
- `FREEZE_v0.2.json`: the freeze manifest, written at the freeze (PREREG §9).
- `FREEZE_RECORD.md`: the freeze record (date, core hash, freeze commit, platform, clone verification, salt,
  sign-off).
- `reviews/`: the instructions and reports of the three blind reviews of the draft (`review1/` to `review3/`).

This README, the repository README, `LICENSE`, `FREEZE_RECORD.md` and `reviews/` are outside the freeze manifest.
